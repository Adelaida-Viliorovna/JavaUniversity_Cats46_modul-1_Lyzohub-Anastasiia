# JavaUniversity_Cats46_modul-1_Lyzohub-Anastasiia

Шифрування та дешифрування текстових файлів (шифр Цезаря)
Програма виконує шифрування, розшифрування та brute force (підбір ключа) для текстових файлів.

Програма реалізує три основні режими роботи:

Encrypt (шифрування) — зміщує символи в тексті на вказаний ключ і створює новий зашифрований файл.

Decrypt (дешифрування) — зсуває символи у зворотному напрямку, відновлюючи початковий текст.

Brute Force (підбір ключа) — перебирає всі можливі ключі, аналізує розшифровані варіанти й вибирає найбільш схожий на природну мову текст.

Працює як в інтерактивному CLI, так і з переданими аргументами.

Підтримує: англійський (великі/малі букви), український (великі/малі букви) та допустимі розділові знаки та символи.

Автоматично визначає мову текстового файлу.

Кінцева програма зібрана у jar-файл.

Програму можна запустити з консолі, передавши аргументи в наступному порядку: command filePath key.
Для режиму Brute Force передавати ключ не треба. Цей режим сам підбере ключ для дешифрування.

Якщо аргументи не передані, програма перейде до інтерактивного CLI.

Результатом роботи програми в папці з початковим файлом з'являється файл з тим самим ім'ям, що і вхідний файл, але з поміткою, в залежності від виконаної операції (наприклад [ENCRYPTED-key]).

Зсув по алфавіту циклічний.

Після розшифрування текст зберігає оригінальне форматування.

Запуск програми:
java -jar JavaUniversity_Cats46_modul-1_Lyzohub-Anastasiia-1.0-SNAPSHOT.jar [command] [filePath] [key]

Де:
- `[command]` — режим роботи: `encrypt`, `decrypt`, або `bruteforce`.
- `[filePath]` — шлях до текстового файлу для обробки.
- `[key]` — числовий ключ для шифрування/дешифрування (необов'язковий для режиму `bruteforce`).

Або запустити без аргументів для інтерактивного режиму.
